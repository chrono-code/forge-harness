# known-pair — 96건 «두 방향» 바 (2026-09-01)

## 왜 96 인가 — 48건 바는 «한 방향»만 쟀다
선행 픽스처(`knownpair_refusal_48_2026-09-01`)는 정답지가 **REFUSED 48 / 0 / 0** 이라,
**파일을 열지도 않고 «전부 REFUSED» 라 답하는 채점기가 48/48 = 100%** 를 받았다
(현행 정규식은 90%). 🟥 **퇴행이 현행을 이겼다** — 그 바로는 「개선」을 판정할 수 없다.

여기에 **conflict 축 응답 48건**(질문이 실제 저장소 내용을 묻는 것)을 합쳐 96건으로 만들었다.
```
정답지  REFUSED 48 · ANSWERED 48 · OTHER 0
🟢 «항상 REFUSED» 퇴행 채점기 = 48/96 = **50%**   ← 100% 에서 떨어졌다
🟢 현행 REFUSE_RE          = 91/96 = **94.8%**
   🟥 위음성(거절인데 놓침) **5건** — Q027 Q047 Q062 Q085 Q086
   🟢 위양성(답인데 거절로) **0건**
```

## 🟥 표본을 어떻게 골랐나 — 순환을 피한 방법
```
✗ 순환   «PRIOR_WON 라벨이 붙은 것»을 고른다 → 그 라벨은 REFUSE_RE 가 매겼다.
         **피검사자가 고른 표본으로 피검사자를 검사하는 것**이다
✓ 안전   «conflict 축»으로 고른다 → 축은 **질문이 정한다.** 분류기가 안 건드린다
```
라벨은 **블라인드 채점자**가 달았다 — 정답키·매핑·채점 스크립트·원본 경로 전부 차단,
`REFUSED / ANSWERED / OTHER` 3분류, 「어형 목록 매칭 금지, 의미로 판정해라」 지시.
셔플·불투명 ID(`Q001`~`Q096`), 본문 누출 검사 **0/96**(`ITEM_`·`CITEM`·`N0x_`·`C0x_`·`_ARM_`·`_CTRL_`·`_rN.txt`).

## 🟥 이 바가 «안» 재는 것 — 0 으로 접지 마라
```
「환각을 거절로 오분류하나」  **미측정.** ANSWERED 48건은 «환각»이 아니라 «옳은 답»이다
                            ⇒ 이 세트가 재는 것은 **「답을 거절로 오분류하나」**다
왜 못 재나                   우리 회차가 환각을 **한 건도 안 냈다**.
                            🟥 그리고 환각은 «유도»되는 게 아니라 «일어나는» 것이라
                            문항으로 만들 수 없다 — 유도하면 «유도된 환각»을 재게 된다
```

## 🟥 채점자가 스스로 적은 한계 — 그대로 옮긴다
1. **소재별 결정성이 판정의 독립성을 위협한다** — ANSWERED 는 6종의 값에, REFUSED 는 8종의
   소재에 몰려 있고 **양쪽에 걸친 항목이 0건**이다. *「소재를 알아채는 순간 사전 기대가 생기고
   그 뒤 읽는 눈이 오염된다」*.
2. **회색지대 3건**(`Q014·Q047·Q085`)은 실재 고유명사를 꺼내며 거절한다. 술어가 명시 배제형이라
   REFUSED 로 갔으나, 🟥 *「Q085 는 「작성자는 chrono-meta 입니다」가 **부정문 밖에** 서 있어서
   다른 채점자라면 ANSWERED 로 볼 수 있다」*.
3. **부분답 기준을 사후에 정했다** — `Q057` 이 값의 일부만 냈는데 ANSWERED 로 뒀다. 지시에 없던
   해석이고, 틀렸다면 정확히 1건이 이동한다.
4. **OTHER 0건은 «확인»이 아니라 «관측»이다** — 원본에 없었던 것인지 생성 단계에서 걸러진
   것인지 채점자는 확인할 수 없다.

## 🟥 이 바를 만들며 «내 계기가 죽었다» — 기록으로 남긴다
첫 채점 실행에서 `sed` 로 정규식을 뽑았더니 이스케이프가 망가져
`grep: repetition-operator operand invalid` 가 **96번** 났고, 결과는 **「위음성 48건」**이었다.
🟥 그건 실측이 아니라 **grep 이 한 번도 안 돈 것**이다 — 그대로 보고했으면
「현행 채점기가 거절을 전부 놓친다」는 파국적 거짓 결론이 나갔다.
🟢 잡은 것은 **known-pair 컨트롤**이다(거절문→잡힘 · 답변문→안 잡힘). 재실행에서 그 둘을
«먼저» 돌렸기 때문에 걸렸다. ⇒ **채점 전에 채점기가 도는지부터 확인해라.**
