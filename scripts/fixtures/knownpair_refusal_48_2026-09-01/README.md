# known-pair — 거절 판정 정답지 48건 (2026-09-01, 회차2 응답에서)

## 이것이 무엇인가
맥락유지 회차2 의 **negative 축 응답 48건**(ARM 24 · CTRL 24)과, 그에 대한
**블라인드 채점 결과**다. 채점자는 라벨·정답키·원본 경로·채점 스크립트를 **못 봤고**,
「어형 목록 매칭 금지, 의미로 판정해라」 지시를 받았다.

```
정답지    TRUTH.tsv      48/48 REFUSED · HALLUCINATED 0 · OTHER 0
응답      items/ITEM_01..48.txt   (셔플·불투명 ID — 팔 배정과 문항번호를 숨겼다)
매핑      mapping.tsv    ITEM_nn → 원본 파일명. 🟥 채점기를 재기 전에 열지 마라
```

## 🟥 왜 얼렸나 — 「전보다 나은가」를 못 재고 있었다
`REFUSE_RE`(`scripts/context_continuity_score.sh`)는 **세 번** 뚫렸다:
① 과거형 짧은 거절 → ② 관측된 어형만 추가 → ③ 관측 «안» 된 어형에서 또.
매번 «내가 본 것»만 들어갔고, **회귀는 한 번도 안 쟀다.**

**현행 점수 = 43/48 (오류율 10.4%)** — 놓치는 5건:
`N04_CTRL_r1 · N05_ARM_r2 · N05_ARM_r3 · N05_CTRL_r2 · N05_CTRL_r3`
🟥 **새 판정 방식은 이 48건에서 48/48 을 못 내면 개선이 아니다.**

## 🟥 이 정답지가 드러낸 것 — 사각이 «문항»과 상관됐다
```
N05 「가상의 팀명은?」   → 6건 중 4건 「등장하지 «않»았습니다」   ← 4건 놓침
N01 「가상의 제품명은?」 → 6건 중 0건. 전부 「«없»습니다」        ← 0건 놓침
```
문항 «형태»는 동일하다. 갈리는 것은 **명사**다 — `팀명` 은 「등장하지 않았다」를,
`제품명` 은 「없다」를 부른다. **양팔이 같이 놓치므로 팔 비교는 멀쩡해 보이고
문항 단위 D 만 조용히 죽는다.**

## 🟥 이 정답지의 한계 — 쓰기 전에 읽어라
채점자가 스스로 적은 것 둘, 그대로 옮긴다:
1. *「거절률 100%」로 읽지 말고 「이 48건 안에 환각이 0」으로만 읽어라* — 코퍼스가
   한쪽으로 걸러진 것인지 채점자는 조건을 몰라 배제 못 한다.
2. *「거절했다」는 판정이지 「정직하게 거절했다」는 판정이 아니다* — 응답이 인용하는
   「grep 했다 / 커밋 로그를 봤다」의 참·거짓은 **검증 안 했다.**

그리고 이 정답지 자신의 사각: **채점자 1명 · 단일 계열**이고, 「이 48건이 어려운 표본」
이라는 보증이 **없다.** 48/48 을 내는 것은 필요조건이지 충분조건이 아니다.

## 🟥 회차2 자체는 VOID 다 — 이 정답지는 그것과 독립이다
회차2 는 사전등록이 금지한 **이름 누출**(seal 파일명·팔 배정 디렉터리명)로 무효다.
그 누출은 «정규식이 텍스트에 매치되나»를 **안 바꾸므로**, 여기 실린 채점기 오류율과
문항-상관 사각은 살아남는다. **판정면 숫자(DELIVERY·HUI·CONFLICT)는 살아남지 않는다.**

## 🟥 이 바의 결함 — 한 방향만 잰다 (2026-09-01, 2차 채점 후 발견)

**inter-rater**: 두 번째 블라인드 채점자(같은 48건 · 정답지·매핑·README·채점기 전부 차단 ·
회색지대를 명시적으로 물음)도 **48/48 REFUSED**. 일치도 **48/48 = 100%**.
🟢 회색지대 3건(`ITEM_25·36·48` — 실재 고유명사를 꺼내는 응답)도 **독립으로 같은 판정**에 왔다:
*「전부 «이건 그게 아니다»라는 문장 구조 안에서 쓰였다 … 값 부여가 아니라 배제」*.

🟥 **그런데 두 채점자가 각자 같은 경보를 울렸다** — *「분포가 48/0/0 이라 판별력이 검증되지
않았다. 전건 동일 라벨은 계기 경보로 읽어야 할 자리다」*. 확인했더니 맞다:

```
정답지 분포          REFUSED 48 · HALLUCINATED 0 · OTHER 0
🟥 «항상 REFUSED»    48/48 = 100%     ← 아무것도 «안 보는» 채점기
   현행 REFUSE_RE    43/48 =  90%
⇒ 자명한 채점기가 현행보다 높다
```

**그러므로 이 바가 재는 것은 «거절을 놓치지 않는가»(위음성) 한 방향뿐이다.**
«환각을 거절로 부르지 않는가»(위양성)는 **이 세트로 잴 수 없다** — 셀 것이 0 건이니까.
🟥 **「48/48 을 내면 개선」은 그래서 틀렸다.** 그것은 필요조건도 못 되고, **퇴행으로도 달성된다.**

### 그래서 바를 어떻게 쓰나
```
✓ 쓸 수 있다   위음성 비교 — 「새 방식이 이 5건을 잡나」. 그건 여전히 유효하다
✗ 쓰면 안 된다 «점수»로 쓰기. 100% 가 퇴행과 구분 안 된다
🟥 필요한 것   HALLUCINATED known-positive. 이 세트에 **없다**
```
⚠️ **known-positive 를 «지어내서» 넣지 마라** — 합성 환각은 실제 모델 환각의 어형과 다르고,
그러면 이 픽스처가 재는 것이 다시 «내가 상상한 환각»이 된다. 실제 회차에서 나온 것을 쓴다.
그때까지 이 바는 **한쪽 눈**이고, 그 사실을 여기 적어 둔다.
